# 操作方法
## 歌詞タイミング記録
1. 改行した歌詞ファイル(.txtなど)を準備する  
2. ターミナルで歌詞タイミングレコーダーを起動  
```uv run lrc_make {タイミングなし歌詞ファイルのパス}```
3. 音声の準備  
音楽プレーヤーを準備して該当の音楽を再生し，0.0秒で一時停止
4. 記録開始  
ターミナルに戻って，スペース押下
音楽再生が始まるので，表示されている歌詞が始まるタイミングでスペースを押下する
5. 保存  
qボタンで記録終了すると，元の歌詞と同じディレクトリに`{ファイル名}_timed.lrc`で自動保存される

## コール記録
1. タイムスタンプがついた歌詞ファイル(.lrc)を準備する  
2. ターミナルでコールレコーダーを起動  
```uv run call_record {タイムスタンプ済みlrcファイルのパス}```   
3. 音声の準備  
音楽プレーヤーを準備して該当の音楽を再生し，0.0秒で一時停止
4. 記録開始  
ターミナルに戻って，スペース押下すると音楽が再生される
音楽に合わせて該当するコールのキーを押す
5. 保存  
再度スペースを押下すると再生が停止し，歌詞にコールのテキストが追記されたコールガイドの生txtと，タイミングを記録したmidiファイルが出力される
