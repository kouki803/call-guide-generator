# 初期設定

1. uvをインストールする  
    ```powershell 
    -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
    ```

    [公式マニュアル](https://docs.astral.sh/uv/getting-started/installation/#standalone-installer)

2. このリポジトリをcloneする

3. ライブラリ，python仮想環境の設定    
    `uv sync`でライブラリなどを同期する

4. png画像生成用の環境構築  
   `uv run playwright install chromium`を実行して、HTMLレンダリング用仮想ブラウザをセットアップ

# 操作方法
## 歌詞タイミング記録
1. 改行した歌詞ファイル(.txtなど)を準備する  
2. ターミナルで歌詞タイミングレコーダーを起動  
```uv run lrc_make {タイミングなし歌詞ファイルのパス}```
3. 音声の準備  
音楽プレーヤーを準備して該当の音楽を再生し，0.0秒で一時停止
4. 記録開始  
ターミナルに戻って，スペース押下
音楽再生が始まるので，表示されている歌詞が始まるタイミングでスペースを押下する
5. 保存  
qボタンで記録終了すると，元の歌詞と同じディレクトリに`{ファイル名}_timed.lrc`で自動保存される

## コール記録
1. タイムスタンプがついた歌詞ファイル(.lrc)を準備する  
2. ターミナルでコールレコーダーを起動  
```uv run call_record {タイムスタンプ済みlrcファイルのパス}```   
3. 音声の準備  
音楽プレーヤーを準備して該当の音楽を再生し，0.0秒で一時停止
4. 記録開始  
ターミナルに戻って，スペース押下すると音楽が再生されるので  
音楽に合わせて該当するコールのキーを押す
5. 保存  
再度スペースを押下すると再生が停止し，歌詞にコールのテキストが追記されたコールガイドの生txtと，タイミングを記録したmidiファイルが出力される

### コール キーバインド早見表

| キー | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| コール | fu | fufuu! | fwfw | PPPH | Yeah! | hi | 警報 | 👏 | 歌詞コール |

## コールガイド画像出力
1. コール記録で出力したtxtを編集して、位置合わせなどを行う  
2. HTMLファイルを生成してプレビューを確認  
  `uv run png_out {編集済みtxtのパス} --preview`  
  ※ HTMLの直編集は現状想定していない
3. 完成版PNGの出力  
  `uv run png_out {編集済みtxtのパス} -t "{曲名}"`  
  ※ 曲名はpngファイル名および画像内の曲タイトルになる  

[Tips]コールの直後に"△, ☆, ◆"を付けると、注釈付き付きコールとして色を変えられる
- src/call_generator/type/html_rendar_config.py の marker_rulesで変更や追加が可能
- マーカーがある場合、曲名の右側に凡例が表示される
