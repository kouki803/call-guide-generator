2. # 概要

## 背景・目的

ライブやイベントにおけるコール表（歌詞や小節進行に合わせた掛け声・手拍子の指示書）の制作は、従来以下のような手作業に依存しており、制作担当者の大きな負担となっていた。

* **小節・拍の手動カウント**: 音源を何度も再生・一時停止・巻き戻しながら、各コールが「何小節目・何拍目」にあるかを耳と目視で数え上げる作業の発生。  
* **フォーマット整形の煩雑さ**: テキストエディタ上で小節番号や拍位置の文字揃え・インデントを手動で整える手間の発生。  
* **ヒューマンエラーによる手戻り**: カウントミスによる小節ズレや拍のズレが発生しやすく、レビューや修正に多大な時間を要する。

本システムは、簡単な打鍵入力から取得したタイミングを、BPM・拍構造に基づいて拍グリッドへ自動吸着（クオンタイズ）し、構造化データとして処理する。 

* **コール表（テキスト）作成の完全自動化**: 入力されたタイミングから小節番号・拍位置を自動計算し、視認性の高いコール表（テキスト／Markdown）を一瞬で自動整形・出力。手動カウントと整形工数を削減する。   
* **動画・音声ガイド制作の効率化**: 「テキストだけでなく、実際の音声入りの方が練習しやすい」という需要に対し、本ツールから同時に出力されるMIDIデータをDAWやサンプラーに読み込ませるだけで、手作業での動画・音声クリップ配置（切り貼り・位置合わせ）を行わずにコールガイド音声トラックを自動生成できる。 

## コンセプト

本アプリは，音ゲー感覚でコールガイドの作成作業を行えるCLI/GUIアプリである．音楽再生に合わせてリアルタイムのキー操作でコールを入力してタイミングデータを記録し，記録をもとにテキスト形式およびMIDIトラックデータなどのコールガイド作成に用いる元ファイルを出力する．

# 4. 機能詳細・仕様
## 4.1. 機能一覧

| 機能ID | 機能名 | 要件区分 | 入力 | 出力 | 処理概要 |
| :---- | :---- | :---- | :---- | :---- | :---- |
| **F-01** | パラメータ管理 | **Must** | 引数 / 設定 | Configs | BPM、拍子、クオンタイズ解像度等の保持 |
| **F-02** | **LRC歌詞読み込み** | **Must** | .lrc ファイル | 歌詞イベント | タイムタグをパースし、BPM基準の小節・拍位置へ射影 |
| **F-03** | タイミング自動補正 | **Must** | 生時刻ログ | CallEvent | 入力時刻を拍グリッドに自動吸着（クオンタイズ） |
| **F-04** | **データ統合・マージ** | **Must** | 歌詞 \+ コール | EventGroup | 小節・拍をキーとして歌詞とコールイベントを結合 |
| **F-05** | **コール表テキスト出力** | **Must** | EventGroup | .txt  | 歌詞とコールが対応したテキスト表を自動生成 |
| **F-06** | MIDI エクスポート | *Nice-to-have* | EventGroup | .mid | 音声ガイド制作を省力化するためのMIDIノート出力 |

## 4.3. 入力仕様

* 歌詞インポート  
  * 入力形式: 標準的なLRCフォーマット（タイムタグ付き歌詞ファイル）  
```plaintext(lrc) 
[MM:SS.ff]hogehoge 
[MM:SS.ff]fugaguga
```
* キーコンフィグ(UserProfile)  
  * key\_num: int  
  * CallEvent  
    * text: str (例: ﾊｲ\!)  
    * midi\_note: int   
    * sound\_path: Path
